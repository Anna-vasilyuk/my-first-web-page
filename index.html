📝 Моя Шпаргалка

Теги, які я вже знаю і використовую:

  • <h1> — головний заголовок
  • <p> — звичайний текст (абзац)
  • <div> — блок-контейнер для всього
  • <button> — кнопка
  • <style> — тег для написання CSS
  • <link> — підключення зовнішнього CSS
  • class="" — ім'я (паспорт) елемента для стилів
